# 画面一覧

元資料: 外部設計書 ver1.0 の「2-1. 画面一覧」。元資料の画面 ID には重複があるため（7、9、14、15）、ここでは No. で区別します。

## 共通（認証まわり）

| No. | 画面 | 説明 |
| --- | --- | --- |
| 1 | 新規登録（メールアドレス入力） | メールアドレスを入力すると、認証メールが届く |
| 2 | 新規登録（メール内 URL から） | ユーザー名とパスワード（英数字・記号・半角スペースで1〜72文字。空白だけは不可）を入力して登録を完了する |
| 3 | ログイン | メールアドレスとパスワードでログインする。利用者は TOP ページへ、大会運営・管理者は運営メニューへ遷移する。メール認証の URL から来た場合は、認証完了を伝えてログインを促し、ログイン後は大会詳細へ遷移する |
| 4 | パスワード変更 | 現在のパスワードと新しいパスワードを入力して変更する |
| 5 | パスワードリセット申請 | 登録メールアドレスを入力し、リセット用 URL をメールで受け取る |
| 6 | パスワードリセット（メール内 URL から） | 新しいパスワードを設定する。リンクの期限（1時間）切れはエラーを出し、申請のやり直しへ案内する。更新後はログイン画面へ |

## 大会運営・管理者向け

| No. | 画面 | 説明 |
| --- | --- | --- |
| 7 | 運営メニュー | ログイン後の最初の画面。問題一覧、大会一覧、大会履歴、ユーザー管理（管理者のみ）への入口 |
| 8 | ユーザー管理 | ユーザーのロール（利用者・大会運営・管理者）を変更する。自分自身のロールは変更できない |
| 9 | 問題一覧 | 「承認済み」「仮保存」「リクエスト済み」を切り替えて表示する。大会運営は仮保存した問題の編集とチェックリクエストの送信、管理者は承認済み問題の編集・削除とリクエストの許可・拒否・結果送信を行う |
| 10 | 問題詳細 | 問題文、難易度、備考、テストケース、模範解答を確認する。管理者はここから編集・削除できる |
| 11 | 問題登録・編集 | 問題を登録・編集する。試し実行でテストケースと模範解答を確認してから仮保存する |
| 12 | 大会一覧 | 作成した大会を状態（下書き・公開済み・開催中・終了）とあわせて表示する。新規作成や各大会の編集・管理へ進む |
| 13 | 大会作成・編集 | 大会名、開始日時、制限時間、概要、出題問題（承認済みのみ）、順位表の更新停止を入力し、下書き保存する |
| 14 | 大会詳細（管理側） | 公開、開始、残り時間の確認、終了後の最終確認と結果公開を行う。参加者一覧とスコアボードへもここから移る。公開時は利用者に通知メールを送ることを確認する。最終結果の確認と結果公開は大会運営だけが行う |
| 15 | 参加者一覧 | 大会にエントリーした利用者を一覧で確認する |
| 21 | スコアボード | 大会中の順位表をリアルタイムで表示する。更新停止後は停止時点の順位表を表示する |

## 利用者向け

| No. | 画面 | 説明 |
| --- | --- | --- |
| 16 | TOP ページ（大会一覧） | ログイン後の最初の画面。開催予定・開催中の大会と自分のエントリー状況を表示し、大会詳細や大会履歴へ進む |
| 17 | 大会詳細 | 大会の概要、開催日時、制限時間を確認し、エントリーや辞退を行う。開催中は問題一覧へ進み、結果公開後は最終結果を確認できる |
| 18 | 問題一覧（大会内） | 開催中の大会で解く問題を選ぶ。残り時間と、各問題の提出状況・得点を表示する |
| 19 | 問題詳細・コード入力 | 問題文を読み、言語を選んでコードを書く。提出前にテスト実行できる。提出時は「提出後は修正できない」ことを確認するポップアップを出す。コピー＆ペーストは禁止 |
| 20 | 採点結果 | 正解したテストケースの数と得点を表示し、問題一覧へ戻る |

要件定義書にあるメール認証画面（未認証の利用者がエントリーしようとしたときに遷移し、認証メールを送信する画面）は、画面一覧には載っていません。
